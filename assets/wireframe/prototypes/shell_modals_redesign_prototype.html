Compare layouts that remove the Sync / New Task / Settings row from the main list, unify modal styling with the app shell, and a Raycast-style footer (selected row primary action + Actions ⌘K). Open this file in a browser and switch tabs.

Idea

Delete ListQuickActions entirely. Main screen = search + results + footer only (matches raycast-redesign intent). List window min-width ~740px (Raycast-like). Entry type is conveyed by icon + meta line colour — not #command / #bookmark hashtags. Footer shows the selected entry’s primary action (e.g. Paste in Terminal ↵) plus Actions ⌘K. User hashtags only, with chroma by library count.

Trade-offs

  • Best visual coherence — zero orphan buttons
  • Mouse-only users use footer primary click or Actions (⌘K)
  • Tag chroma reuses filter facet counts — no new data source
  • Lowest implementation risk — remove row + restyle modals

Main list — all five entry types · min-width 740px · no type hashtags · tag chroma by count
