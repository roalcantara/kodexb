Icon Filter File (assets/images/) Rationale

Applied vs not applied (immediate apply)

Toggling a row calls onChange at once: applied = that facet is in the current filter (isOn in code). In this prototype, only a ✓ marks applied rows (no accent tint on the row or on the mark). Not applied = same row when that facet is off — muted label, no check. There is no separate “pending” row state.
